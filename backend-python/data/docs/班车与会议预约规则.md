# 班车与会议预约规则

员工通勤班车面向全体在职员工开放，每人每天最多预约一个班次座位。预约成功后座位保留到发车前 15 分钟，超时未上车座位自动释放。

总裁班车仅限集团高管预约。普通员工与实习生即使提交预约，系统也会按权限规则直接拒绝，不占用座位。

会议室预约需要提前一天在系统中提交，使用时段以半小时为最小单位。第一会议室仅限技术部与综合管理部使用，其他部门预约会被拒绝。

预约一律通过对话助手提交，助手会先核对您的职级与所在部门，再执行下单。放行与否以系统权限规则为准，助手不做额外判断。

福利礼包按季度发放，全员可约，先到先得，每人每季度限领一份。

员工在预约前应先在对话中说明要预约的资源类型与日期，例如“帮我预约下周一的员工班车”，系统会根据资源名称自动匹配。

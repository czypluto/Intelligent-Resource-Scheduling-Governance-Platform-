# 儿童与学生票规则

儿童票：年满6周岁且未满14周岁的儿童应当购买儿童优惠票；6周岁以下且不单独占用席位可免费乘车（一名成人可携带一名免票儿童），超过一名时超出儿童需购儿童票。儿童优惠票按相应席别票价的50%执行。

身高不再是儿童票划分依据，以购票时登记的年龄为准。儿童不能单独乘车，须由成人同行。

学生票：全日制大中专院校在校学生可购买学生优惠票，限本人寒暑假期间乘车，区间为家庭与学校之间。学生票动车组二等座按公布票价的75%执行，普速列车硬座按公布票价的50%执行。

使用学生票进站乘车须带学生证与火车票学生优惠卡，每学年可购买四次单程优惠票。优惠乘车区间与优惠卡登记的区间不符时不能享受优惠。
